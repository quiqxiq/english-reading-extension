🧩 Custom AI Prompts Variable Guide

You are free to customize the System Prompt and User Prompt below according to your learning preferences. The system will automatically interpolate the following variables when queries are executed:

[WORD] The target English word being looked up
[SENTENCE] The full context sentence containing the word
[TARGET_LANG] The language being studied (English)
[INTERFACE_LANG] The interface / output language (e.g. Indonesian)
